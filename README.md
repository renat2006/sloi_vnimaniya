# Слои внимания

Интерактивный перформанс о стратиграфии внимания. Браузерная колба наполняется
песком, пока страница удерживает фокус; каждое переключение вкладки или окна
откладывает холодный слой разрыва. По завершении сеанса колба превращается в
керн — линейный срез, который читается как порода.

## Как запустить

```bash
python3 -m http.server 4173
```

Затем открыть http://localhost:4173 — сборка не нужна, это статические файлы
и нативные ES-модули.

## Устройство

| Файл | Назначение |
| --- | --- |
| `js/geom.js` | профиль колбы, объём → высота, морфинг колба ⇄ керн |
| `js/paint.js` | отрисовка страт: градиенты слоёв, дымка возвращения, зерно |
| `js/stage.js` | сцена: стекло, струя, частицы, шкала, церемония извлечения |
| `js/session.js` | модель сеанса, склейка микроразрывов, метрики |
| `js/store.js` | локальный архив кернов, учебные образцы |
| `js/archive.js` | зал собрания: сетка кернов, недельный срез, экспорт PNG |
| `js/audio.js` | гранулярный шум потока и дрон, меняющие тембр на разрыве |

## Модель

- Высота слоя пропорциональна его длительности; ширина колбы искажает время,
  керн его выпрямляет.
- **Дымка возвращения** — первые 70 секунд каждого слоя после разрыва
  отрисовываются с примесью холодного цвета: остаточное внимание.
- **Индекс дробления** = 1 − Σ(fᵢ/F)², где fᵢ — длительности непрерывных
  эпизодов фокуса. Монолит даёт 0, множество равных обрывков — близко к 1.
- Разрывы короче 350 мс не считаются: это переключения раскладки и прочий шум.

Данные не покидают браузер: архив живёт в `localStorage`.
